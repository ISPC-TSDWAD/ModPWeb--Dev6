# Bienvenido a la Wiki de EduTools 🚀

**EduTools** es un Sandbox Pedagógico y Gestor de Recursos Educativos desarrollado por el **Equipo DEV6** para el Instituto Superior Politécnico Córdoba (ISPC). Nuestro sistema permite a docentes y asesores pedagógicos crear, gestionar y formatear contenido educativo de manera ágil, conectándose a una API centralizada en Django.

### 2. Project Charter (PMI)
- 🎯 **Criterios de Éxito:** Entrega del MVP funcional en Angular + Django, despliegue exitoso en entorno local, adopción de metodologías ágiles comprobables y aprobación de todas las evidencias.
- 🚧 **Restricciones del Proyecto:** El tiempo límite de desarrollo es estricto (marcado por el calendario académico del ISPC). Se debe utilizar obligatoriamente el stack MEAN/Django sin frameworks de CSS de alto nivel (como Tailwind o Bootstrap) en el layout general salvo excepciones justificadas.
- 🤔 **Supuestos Iniciales:** Los usuarios finales poseen conocimientos básicos en ofimática. El servidor institucional soportará tráfico de hasta 100 usuarios concurrentes.
