  ENTIDADES DEL SISTEMA (adaptadas del prototipo Stitch):
  ───────────────────────────────────────────────────────

  ┌──────────────────────────────────────────────────────────────────┐
  │  USUARIO                                                        │
  │  ─────────                                                      │
  │  Extiende el modelo AbstractUser de Django.                     │
  │  Agrega un campo "rol" con valores:                             │
  │    - admin       → Administrador                                │
  │    - asesor      → Asesor Pedagógico (default)                  │
  │    - maquetador  → Maquetador                                   │
  │  Campos heredados: id, username, password, first_name,          │
  │                    last_name, email, is_active, date_joined      │
  └──────────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────┐
  │  CATEGORIA                                                      │
  │  ──────────                                                     │
  │  Categoría principal de componentes pedagógicos.                │
  │  Ejemplos: Llamados a la Acción (CTA), Estándares de Diseño,   │
  │  Recursos Multimedia, Herramientas Interactivas, Evaluaciones.  │
  │  Campos: id, nombre (unique), descripcion, activa,              │
  │          creado_en, actualizado_en                               │
  └──────────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────┐
  │  ASIGNATURA                                                     │
  │  ───────────                                                    │
  │  Materia académica para organizar recursos por área.            │
  │  Ejemplos: Matemáticas Avanzadas, Historia Universal,           │
  │  Química Orgánica, Programación III.                            │
  │  Campos: id, nombre (unique), descripcion, activa,              │
  │          creado_en, actualizado_en                               │
  └──────────────────────────────────────────────────────────────────┘

  ┌──────────────────────────────────────────────────────────────────┐
  │  RECURSO                                                        │
  │  ────────                                                       │
  │  Componente pedagógico creado desde el Sandbox.                 │
  │  Tipos: Video CTA, Acordeón, Infografía, Cuestionario,         │
  │         Lectura, Actividad.                                     │
  │  Campos: id, titulo, descripcion, tipo, contenido, url,         │
  │          activo, creado_en, actualizado_en                       │
  │  Foreign Keys:                                                  │
  │    - categoria_id   → Categoria   (ON DELETE PROTECT)           │
  │    - asignatura_id  → Asignatura  (ON DELETE PROTECT)           │
  │    - creado_por_id  → Usuario     (ON DELETE CASCADE)           │
  └──────────────────────────────────────────────────────────────────┘

  RELACIONES:
    USUARIO    ──(1:N)──> RECURSO    → Un usuario crea muchos recursos.
    CATEGORIA  ──(1:N)──> RECURSO    → Una categoría agrupa muchos recursos.
    ASIGNATURA ──(1:N)──> RECURSO    → Una asignatura tiene muchos recursos.

3. BACK-02: ENDPOINTS Y LÓGICA DE NEGOCIO
================================================================================

  ENDPOINTS DE LA API REST:
  ─────────────────────────

  Base URL: http://127.0.0.1:8000/api/

  ┌────────────────────────────┬──────────┬──────────────────────────────┐
  │  Endpoint                  │  Método  │  Descripción                 │
  ├────────────────────────────┼──────────┼──────────────────────────────┤
  │  /api/usuarios/            │  GET     │  Listar todos los usuarios   │
  │  /api/usuarios/            │  POST    │  Crear un nuevo usuario      │
  │  /api/usuarios/{id}/       │  GET     │  Obtener usuario por ID      │
  │  /api/usuarios/{id}/       │  PUT     │  Actualizar usuario          │
  │  /api/usuarios/{id}/       │  PATCH   │  Actualizar parcialmente     │
  │  /api/usuarios/{id}/       │  DELETE  │  Eliminar usuario            │
  ├────────────────────────────┼──────────┼──────────────────────────────┤
  │  /api/categorias/          │  GET     │  Listar todas las categorías │
  │  /api/categorias/          │  POST    │  Crear nueva categoría       │
  │  /api/categorias/{id}/     │  GET     │  Obtener categoría por ID    │
  │  /api/categorias/{id}/     │  PUT     │  Actualizar categoría        │
  │  /api/categorias/{id}/     │  PATCH   │  Actualizar parcialmente     │
  │  /api/categorias/{id}/     │  DELETE  │  Eliminar categoría          │
  ├────────────────────────────┼──────────┼──────────────────────────────┤
  │  /api/asignaturas/         │  GET     │  Listar asignaturas          │
  │  /api/asignaturas/         │  POST    │  Crear nueva asignatura      │
  │  /api/asignaturas/{id}/    │  GET     │  Obtener asignatura por ID   │
  │  /api/asignaturas/{id}/    │  PUT     │  Actualizar asignatura       │
  │  /api/asignaturas/{id}/    │  PATCH   │  Actualizar parcialmente     │
  │  /api/asignaturas/{id}/    │  DELETE  │  Eliminar asignatura         │
  ├────────────────────────────┼──────────┼──────────────────────────────┤
  │  /api/recursos/            │  GET     │  Listar todos los recursos   │
  │  /api/recursos/            │  POST    │  Crear nuevo recurso         │
