Aplicación Web Angular y Django RF 

Implementación completa 

En esta tercera evidencia, el equipo deberá avanzar en la construcción funcional del sistema 
incorporando  los  contenidos  trabajados  en  el  módulo,  integrando  frontend  y  backend  bajo 
una arquitectura moderna. 

El  objetivo  de  este  sprint  es  consolidar  una  aplicación  funcional  escalable,  modular  y 
conectada  mediante  APIs  REST,  aplicando  buenas  prácticas  de  desarrollo  profesional, 
organización del código y trabajo incremental. 

Durante este Sprint el equipo deberá: 

Implementar funcionalidades reales del sistema utilizando Angular 21 en el frontend. 

● 
●  Desarrollar servicios backend utilizando Django Rest Framework. 
● 
Integrar frontend y backend mediante consumo de APIs REST. 
●  Aplicar arquitectura modular, reutilización de componentes y separación de 

responsabilidades. 

●  Gestionar estados de navegación, formularios, autenticación y persistencia de datos. 
●  Documentar avances técnicos y evidencias funcionales del proyecto.
