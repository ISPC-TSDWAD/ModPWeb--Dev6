5. Pautas y Referencias Institucionales

  • Uso obligatorio de paleta institucional (Gamas de azul, teal y gris).
  • Alineación y legibilidad estándar de acuerdo a la normativa WCAG 2.1 AA.
  • Toda imagen debe contener su respectiva etiqueta ALT descriptiva.
  • Jerarquía de encabezados respetando el orden lógico H1, H2, H3.

6. Estándares de Recursos Visuales

  • Tipografía Principal: Inter (Sans-serif) para asegurar excelente legibilidad en pantalla.
  • Bordes: Redondeados de 4px para elementos UI de contenido interactivo.
  • No abusar de colores de error (rojo) salvo excepciones críticas y notificaciones obligatorias.
  • Las animaciones deben ser sutiles y respetar la preferencia de "reduced motion" del SO.
